# 需求

使用者於 2026-09-13 要求主導覽增加 Screen Page，設定與帳號移到右上角。Screen 是跨筆記本的閱讀空間：以泳道為單位排列，可釘選筆記、資料夾、資源與 YouTube。筆記以閱讀為主，需要時開啟既有編輯器。

最新確認的配置單位是 row（泳道）。自訂泳道先建立空白列，再放入項目；動態泳道依指定標籤或資料夾列出內容。泳道可選縮圖、小、中三種呈現；圖片只改顯示大小。項目可在自訂泳道內及泳道之間拖曳排序，動態泳道的內容不可拖入或拖出。泳道編輯視窗可重新命名、拖曳排序及移除泳道，移除不刪除來源資料。

使用者已撤回任意 grid、手勢調整尺寸及 Redis 儲存。配置改用工作區根目錄 `.github-notes-screen.yaml`，透過工作區原有 Git 流程同步。滾輪支援 Y 轉 X，按住 Alt 暫停；卡片內文保留獨立垂直閱讀。

同步完成 Markdown 相對路徑、跨筆記本連結、外部連結、標題錨點、圖片預覽與資源庫定位；延續全域筆記本切換、Agent 依真實資料夾顯示、Logo、favicon、基本 SEO 與版面整理。
