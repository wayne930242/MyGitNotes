# 可觀察合約

- 主導覽為筆記、Agent 系統、資源庫、Screen；設定與帳號在右上角。全域筆記本選擇只影響 Screen 新增項目的預設來源，不過濾已釘選內容。
- 自訂泳道可新增、取消釘選，拖曳排序或跨自訂泳道移動；拖到動態泳道不接受。側欄直接拖曳泳道排序；鉛筆開啟重新命名，移除需確認。
- 動態標籤泳道可選所有筆記本或單一筆記本；資料夾泳道選擇特定筆記本與資料夾，可包含子資料夾。內容隨工作區資料重新載入或更新而重新計算；隱藏筆記不列入動態內容。
- 每條動態泳道可獨立選擇標題、更新時間、建立時間升降冪，或狀態工作流程順序，並保存於 YAML。未設定排序的既有泳道保留原本筆記在前、資源在後的標題順序。明確設定後筆記與資源共同排序；資源沒有建立時間時以修改時間代替。
- 縮圖呈現標題與摘要，小／中呈現獨立可捲動內容。圖片保持原比例，三種呈現只改大小。YouTube 首先呈現封面，點播放後載入官方嵌入播放器，支援起始時間。
- 預設使用原生捲動。僅 Alt + Y 將泳道內滾輪轉成 X，且在水平邊界仍攔截垂直捲動；觸控板原生 X 與縮放手勢不攔截。提供左右按鈕和鍵盤拖曳。
- YAML 只保存參照、泳道名稱、篩選條件、順序與檢視尺寸，不複製筆記、圖片或憑證。檔案屬於工作區資料，Core 不得追蹤或覆蓋。
- 本地 main 儲存 YAML 後由既有 Git 差異／提交流程同步；遠端 main 需要登入與寫入權限，單檔提交至所連工作區。跨機器以 Git 同步此檔案，配置由該工作區共用。
- 儲存檢查版本，衝突不覆蓋；本機草稿依工作區隔離，可匯出 YAML 或明確確認後重新載入。配置讀取失敗時不可寫入。Core 與唯讀來源不得修改配置。
- Markdown 連結以來源檔案解析；一般點選可開啟筆記、資料夾、HTTP(S) 或 mailto，圖片可預覽及定位資源庫。內部導覽先完成既有編輯器待儲存內容；失敗時保留草稿及當前編輯器。
