# 筆記資料夾操作

使用者確認：筆記資料夾需要新增、刪除、拖曳排序與調整層級。刪除資料夾時預設把內容移到上層，也能指定其他資料夾；不刪除內部筆記。產品定位為高密度功能性筆記本，操作維持在同一筆記本內。

資料夾使用既有實體路徑與 `_dir.yml`，順序以兄弟資料夾的 order 保存。拖到前後插入線可排序，拖到資料夾中央可成為子資料夾。保留非拖曳的移動選單。空筆記本也能建立第一個資料夾。

刪除會移動直接子項目，保留子資料夾結構；有同名衝突時整個操作失敗，使用者另選位置。禁止移入自己或子孫，也禁止操作筆記本根目錄、資源與 Agent 保護路徑或符號連結。操作前檢查版本，失敗保留原始內容。

共同規劃函式產生路徑搬移與 metadata 更新；本地以可回復的檔案操作套用，遠端用單一 Git commit。移動時同步可解析的 Markdown 路徑與 Screen 參照。完成後重新載入資料夾及筆記，並導覽到新位置。

測試在隔離工作區驗證：新增與重名、同層排序、跨層移動、循環拒絕、刪除預設上層／指定位置、碰撞不覆蓋、未知 metadata 保留、Markdown 與 Screen 引用、版本衝突及唯讀保護；瀏覽器驗證實際拖曳與對話框。


## 屏幕與攤開補充回饋

使用者於本輪補充並確認：移除 Screen Page 標題、介紹及 YAML 技術提示；全域泳道操作移至一致寬度的 sidebar；配置自動保存並接入共用 commit 提醒。中文採「屏幕」，以三折 GM 屏風圖示呈現；空白狀態文案為「將專注留給當下」。筆記增加「攤開」，保留目前資料夾範圍並包含全部子孫筆記。

本地屏幕修改自動寫入 YAML；遠端保留瀏覽器草稿，由既有提交視窗與選取的筆記組成單一 Git commit。提交前比對屏幕基底，衝突時保留草稿；切換頁面不會中止待完成的自動保存。本地資料夾操作與屏幕寫入共用工作區序列，避免互相覆蓋。

## 實際驗證

- 刪除視窗預設選中上層，改選筆記本最上層後，子資料夾及其 Markdown 原文完整保留。
- 攤開在子資料夾範圍只顯示其子孫筆記，回到根目錄後列出根目錄與子資料夾筆記；390px 下也能透過檢視選單切換。
- 屏幕調整尺寸後立即切換筆記頁，磁碟 YAML 仍正確自動更新；共用提交視窗只選屏幕配置後，隔離 Git 提交只包含該檔案。
- 1280px 版面對齊 sidebar；390px 泳道抽屜可開啟，頁面 scrollWidth 等於 viewport，沒有整頁水平溢出。
- 核心測試涵蓋路徑碰撞、循環與保護路徑、metadata 保留、Markdown／屏幕參照；HTTP 測試涵蓋 stale revision、唯讀與注入磁碟錯誤後回復。

- 最終產品驗證：完整 build 通過；40 個測試檔案、192 個案例通過。遠端筆記與屏幕配置可合併為單一 commit，過期屏幕基底拒絕寫入。

## 索引編輯與設定游標補充

新增資料夾提供預設未勾選的「建立資料夾後，建立並編輯 index.md」。管理既有資料夾依精確的 index.md 路徑顯示建立或編輯，包含隱藏筆記與瀏覽器工作草稿；README.md 保留原文。索引沿用既有筆記編輯器，本地寫入工作目錄，遠端保存瀏覽器草稿，均沿用明確提交流程。關閉索引回到索引所屬資料夾。

若資料夾成功建立而索引建立失敗，管理視窗保留明確錯誤與重試入口，不重建資料夾。唯讀模式不顯示異動入口。

設定清單使用深色輸入背景；原本游標顏色來自主題，淺色主題下與輸入背景同色。將該欄位游標改為跟隨欄位文字色，六種主題皆經瀏覽器聚焦、計算色彩與鍵盤輸入確認。

實測立即關閉本地編輯器會早於自動存檔而留下恢復草稿。關閉現在等待寫入成功、清除恢復草稿，並抑制關閉中的自動存檔重建草稿；失敗時維持編輯器供重試。沒有修改的本地索引不額外寫入。

刪除資料夾並上移內容時，僅移除被刪除資料夾本身的 `_dir.yml`，不搬往目的地；目的地既有 metadata 保持原文，原本沒有 metadata 時不新增；子資料夾連同各自的 `_dir.yml` 保留。核心共用規劃函式及本地 HTTP 實際檔案測試涵蓋移到根目錄與指定資料夾。

驗證：`pnpm build`、`pnpm test`（41 檔／202 案例）、`scripts/qa-folder-editing.mjs`、既有 `qa-folder-index.mjs` 與 `qa-working-notes.mjs` 通過。新瀏覽器案例包含六種主題、可選索引、新增子資料夾、隱藏／空白原文保留、README 保留、立即關閉存檔、部分失敗重試、390px 繁體中文視窗，以及模擬 GitHub 來源的新舊索引草稿重載與唯讀限制。測試只使用隔離資料，未寫入使用者筆記。
