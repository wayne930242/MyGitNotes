# 筆記資料夾操作

使用者確認：筆記資料夾需要新增、刪除、拖曳排序與調整層級。刪除資料夾時預設把內容移到上層，也能指定其他資料夾；不刪除內部筆記。產品定位為高密度功能性筆記本，操作維持在同一筆記本內。

資料夾使用既有實體路徑與 `_dir.yml`，順序以兄弟資料夾的 order 保存。拖到前後插入線可排序，拖到資料夾中央可成為子資料夾。保留非拖曳的移動選單。空筆記本也能建立第一個資料夾。

刪除會移動直接子項目，保留子資料夾結構；有同名衝突時整個操作失敗，使用者另選位置。禁止移入自己或子孫，也禁止操作筆記本根目錄、資源與 Agent 保護路徑或符號連結。操作前檢查版本，失敗保留原始內容。

共同規劃函式產生路徑搬移與 metadata 更新；本地以可回復的檔案操作套用，遠端用單一 Git commit。移動時同步可解析的 Markdown 路徑與 Screen 參照。完成後重新載入資料夾及筆記，並導覽到新位置。

測試在隔離工作區驗證：新增與重名、同層排序、跨層移動、循環拒絕、刪除預設上層／指定位置、碰撞不覆蓋、未知 metadata 保留、Markdown 與 Screen 引用、版本衝突及唯讀保護；瀏覽器驗證實際拖曳與對話框。


## 屏幕與攤開補充回饋

使用者於本輪補充並確認：移除 Screen Page 標題、介紹及 YAML 技術提示；全域泳道操作移至一致寬度的 sidebar；配置自動保存並接入共用 commit 提醒。中文採「屏幕」，以三折 GM 屏風圖示呈現；空白狀態文案為「將專注留給當下」。筆記增加「攤開」，保留目前資料夾範圍並包含全部子孫筆記。

本地屏幕修改自動寫入 YAML；遠端保留瀏覽器草稿，由既有提交視窗與選取的筆記組成單一 Git commit。提交前比對屏幕基底，衝突時保留草稿；切換頁面不會中止待完成的自動保存。本地資料夾操作與屏幕寫入共用工作區序列，避免互相覆蓋。
