# 可觀察規格

使用者 2026-09-13 以「好的」確認先前實際瀏覽四頁所得的問題與統一方向。

桌面四頁的側欄右界及內容標題左界一致；搜尋／檢視／新增筆記位於筆記頁操作區。Agent 文件繼續有自己的儲存狀態與編輯模式工具列。資源依筆記本及資料夾導覽，設定可跳至現有設定段落。

側欄外容器不設內容內距，內距由捲動內容承擔；不在標籤清單再建立捲動容器。側欄與主要內容可獨立捲動。小螢幕保留底部四個入口、筆記抽屜與 Agent 文件選擇器；操作不能超出可視範圍。

保留 URL、篩選與資料變更語意，不新增權限或後端功能。所有外觀採主題變數。
