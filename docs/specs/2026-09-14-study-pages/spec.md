# 可觀察契約

1. 一般 Markdown 閱讀不變。分頁閱讀只將正文頂層獨立 `---` 分頁，保留前置資料、標題、巢狀內容及程式碼原意。
2. 河道卡片可進入單卡閱讀與記憶模式。正面為第一頁、背面為後續頁；沒有分頁時使用標題與內文。
3. 隨選閱讀可略過、明天、三天後及自訂延後；固定間隔可配置序列。閱讀及延後不產生成功回想紀錄。
4. 記憶模式揭示答案後才能用四級評分更新 FSRS，配置目標保留率，顯示下一次日期。暫停與恢復複習獨立於 note status。
5. 河道保存學習篩選（全部、到期、未來、暫停）與最早到期排序。自選卡片仍可手動開啟。
6. 固定卡片 ID、頁面對應及事件保存在使用者工作區，支援一份筆記多卡的模型。唯一相同內容可在頁面重排後接續；有歧義或內容改變時先重新配對。
7. 每個學習操作明確保存，支援最近操作撤銷。重新載入可還原；過期版本寫入回報衝突並保留當前畫面以供重試。
8. local 與 GitHub 來源遵循 main 寫入、路徑與 symlink 限制；工作區 Git 更新保留學習檔，正文與未知 metadata 不變。
9. 手機左右滑動在閱讀模式換頁，在答案揭示後評分；完整按鈕操作、可捲動內容及可到達的關閉／撤銷控制。

本次提供多卡與遮罩的資料基礎；多題編輯器、反向／填空卡建立工具、完整簡報模式及參數最佳化屬後续功能。

Reality anchor：一次性 main 工作區的核心／HTTP 測試與瀏覽器操作，核對重新載入及保存檔案；pnpm test、pnpm build。產品 core 提交／推送與 trpg-notes 匯入／驗證分別記錄。
