# 可觀察契約

1. 一般 Markdown 閱讀不變。分頁閱讀只將正文頂層獨立 `---` 分頁，保留前置資料、標題、巢狀內容及程式碼原意。
2. 閱讀與學習由泳道的獨立按鈕進入全螢幕頁，與泳道 view 分開。頁面一次顯示一張卡片並直接操作，保存成功後換下一張。正面為第一頁、背面為後續頁；沒有分頁時使用標題與內文。
3. 隨選閱讀可略過、按熟悉程度安排目的階段或自訂延後。階段間隔可配置。閱讀及延後不產生成功回想紀錄。
4. 學習版型先揭示答案，再用四級熟悉程度自動更新 note status：忘記回第一階段、吃力留在本階段、記得進一階、輕鬆進兩階（超過上限到最後階段），也可配置輕鬆直接到最後階段。間隔由抵達階段決定，河道可配置狀態與間隔。既有 FSRS 紀錄保留。
5. 學習配置提供全部、到期、未來、暫停篩選，與階段一起套用或取消並保存於泳道，固定最早到期排序。自選卡片仍可手動開啟。
6. 固定卡片 ID、頁面對應及事件保存在使用者工作區，支援一份筆記多卡的模型。唯一相同內容可在頁面重排後接續；有歧義或內容改變時先重新配對。
7. 每個學習操作明確保存，支援最近操作撤銷。重新載入可還原；過期版本寫入回報衝突並保留當前畫面以供重試。
8. local 與 GitHub 來源遵循 main 寫入、路徑與 symlink 限制；工作區 Git 更新保留學習檔，正文與未知 metadata 不變。
9. 手機左右滑動逐頁翻閱，熟悉程度使用明確按鈕。完整按鈕操作、可捲動內容及可到達的關閉／撤銷控制。

10. 一般泳道 status 與排序整合在工具列，標籤單行；學習篩選只顯示在學習配置。手機以「篩選與排序」入口展開設定，常用操作維持單列，卡片以觸控捲動。
11. 筆記、屏幕、資源庫、Agent 及設定頁的手機側欄開關，統一位於頁首筆記本選擇同列；桌面側欄維持原本位置。

12. Live Preview 編輯器將正文頂層 `---` 顯示為可見分頁邊界與頁面間距；Source 保留原始標記，程式碼內的 `---` 維持程式碼。

補充確認：使用者要求河道單卡版型與 note status 自動流轉，確認四級規則，並更正「輕鬆」為跳兩階或最後階段，間隔由階段決定。

13. 每個泳道透過開始學習按鈕提供 `/screen/lanes/<id>` 專屬全螢幕學習頁，保留選卡、翻頁、評分、撤銷及編輯設定；直接載入、編輯器返回與返回屏幕皆保留來源。缺少泳道時顯示可返回的提示。
14. 揭示答案後可逐頁返回題目、再向前查看答案。學習頁左右箭頭依篩選與到期順序切換前後卡片，切卡不寫入學習事件或改變 status。
15. 新增泳道預設一般版型，學習是獨立入口，進出學習不修改泳道 view、一般排序或筆記。階段與間隔從學習頁進入泳道編輯，套用或取消共同處理；一般泳道不顯示學習篩選。舊版 reading／study view 讀取為 small，保留配置與紀錄。
16. 學習頁 navbar 保留返回、撤銷與設定。固定 Page 1／2／3 頁序與翻頁、前後卡片及略過集中於底部，熟悉程度位於翻頁列上方，揭示前收起，翻開內容後以 180ms 動畫向上展開；系統減少動態效果時立即呈現。選卡及自訂延後收進更多操作；撤銷固定在頂部設定旁，無可撤銷紀錄時停用，320px 與低高度畫面仍可操作。
18. 一般泳道筆記卡移除開啟圖示，點擊卡片空間即可開啟；保留原有連結、控制、文字選取與鍵盤標題按鈕。
17. 共用 Button 及單一按鈕 CSS 定義預設、主要、選中、hover、focus、disabled 狀態。學習頁使用共用狀態，不另寫選中配色；所有內建主題的啟用按鈕 hover 文字對比至少 4.5:1。
