# MyGitNotes 與儲存來源

MyGitNotes 是以 Git 保存的個人筆記與文件工作區。平台指 GitHub 或 GitLab；站台指平台所在的服務網址；儲存庫是筆記的來源。每個部署指定一個平台、站台、儲存庫與分支。GitLab.com 與自架 GitLab 使用相同的工作區操作。

# 工作區呈現

Screen Page 是筆記本的閱讀空間，以泳道組織內容。每條泳道屬於一個筆記本，只收該筆記本的內容；Screen 只顯示目前筆記本的泳道。自訂泳道持有項目參照；動態泳道持有 tag 或 folder 查詢。泳道採用縮圖、小、中版型，另以獨立按鈕進入學習頁，卡片可以獨立捲動，需要修改時開啟原本編輯器。

Screen 不擁有原始資料。取消釘選或移除泳道不刪除筆記、資料夾、資源。動態內容不可拖入或拖出，只有自訂項目支援同一筆記本內的泳道內與跨泳道拖曳。

工作區根目錄 `.github-notes-screen.yaml` 保存 Screen 配置，屬於使用者資料，透過既有 Git 工作流程跨機器同步。本機草稿只是尚未儲存的恢復副本，不代表配置已同步。

# 關聯圖與河道（已確認方向，待實作）

## 用語

**河道**：由自訂項目參照或動態查詢界定的內容集合，可以採用不同顯示模式。既有文件及介面亦稱「泳道」，兩者指同一概念。

**關聯圖檢視**：由指定筆記集合及其內容連結形成的空間呈現。河道可以作為它的內容範圍，也可以直接使用關聯圖顯示模式。

**筆記節點**：筆記在關聯圖中的同一個物件，可以收合為節點或展開為可編輯筆記。展開不建立另一份筆記，多選與展開是不同操作。

使用者可將關聯圖內多選的筆記存成河道，再由河道開啟關聯圖。河道持有筆記參照，正文與連結仍由原筆記擁有；移除河道或收合節點不刪除原筆記。

# 分頁與學習

正文頂層 `---` 將筆記分為線性頁面。一般閱讀仍以分隔線呈現；分頁閱讀依原始順序翻頁。學習卡以頁面對應定義題目與答案，每張卡有固定身分與獨立記憶排程。一份筆記可對應多張卡；反向卡與填空卡共用原始內容。

閱讀與回想事件分開記錄。學習流程以 note status 定義階段，熟悉程度控制前進或退回，複習間隔由目的階段決定。階段與間隔由學習頁的泳道編輯視窗配置；一般泳道保留原本操作。河道引用同一份學習資料，移除項目保留學習紀錄。工作區 `.github-notes-study.yaml` 保存卡片身分、階段、到期及事件，透過 Git 跨裝置同步。

閱讀／學習頁一次顯示一張卡片，題目及答案揭示後可來回翻頁，切卡不寫入評分。`/screen/lanes/<id>` 是泳道的專屬全螢幕學習頁，開啟時切換到泳道所屬筆記本，固定最早到期排序，保留操作與編輯器返回來源，與泳道 view 分開。

上次移動時間是使用者最近一次成功提交熟悉程度的時間；忘記、吃力、記得、輕鬆皆算移動，保留原階段也重新計時。到期由該次移動時間加目的階段間隔決定。自訂延後調整到期，保留上次移動時間；撤銷還原前次時間。翻頁、切卡與略過屬於閱讀操作。
