# MyGitNotes 與儲存來源

MyGitNotes 是以 Git 保存的個人筆記與文件工作區。平台指 GitHub 或 GitLab；站台指平台所在的服務網址；儲存庫是筆記的來源。每個部署指定一個平台、站台、儲存庫與分支。GitLab.com 與自架 GitLab 使用相同的工作區操作。

# 工作區呈現

Screen Page 是工作區共用的跨筆記本閱讀空間，以泳道組織內容。自訂泳道持有項目參照；動態泳道持有 tag 或 folder 查詢。泳道採用縮圖、小、中版型，另以獨立按鈕進入學習頁，卡片可以獨立捲動，需要修改時開啟原本編輯器。

Screen 不擁有原始資料。取消釘選或移除泳道不刪除筆記、資料夾、資源；切換筆記本只改變新增項目的預設來源。動態內容不可拖入或拖出，只有自訂項目支援泳道內與跨泳道拖曳。

工作區根目錄 `.github-notes-screen.yaml` 保存 Screen 配置，屬於使用者資料，透過既有 Git 工作流程跨機器同步。本機草稿只是尚未儲存的恢復副本，不代表配置已同步。

# 分頁與學習

正文頂層 `---` 將筆記分為線性頁面。一般閱讀仍以分隔線呈現；分頁閱讀依原始順序翻頁。學習卡以頁面對應定義題目與答案，每張卡有固定身分與獨立記憶排程。一份筆記可對應多張卡；反向卡與填空卡共用原始內容。

閱讀與回想事件分開記錄。學習流程以 note status 定義階段，熟悉程度控制前進或退回，複習間隔由目的階段決定。階段與間隔由學習頁的泳道編輯視窗配置；一般泳道保留原本操作。河道引用同一份學習資料，移除項目保留學習紀錄。工作區 `.github-notes-study.yaml` 保存卡片身分、階段、到期及事件，透過 Git 跨裝置同步。

閱讀／學習頁一次顯示一張卡片，題目及答案揭示後可來回翻頁，切卡不寫入評分。`/screen/lanes/<id>` 是泳道的專屬全螢幕學習頁，固定最早到期排序，保留操作與編輯器返回來源，與泳道 view 分開。
