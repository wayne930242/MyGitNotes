# 分頁閱讀與記憶練習

在 Screen 河道的筆記卡片按「閱讀／複習」。示範原稿位於 [examples/study](../../examples/study/)；將其內容複製到獨立的 main Git 工作區，即可練習保存與撤銷。

正文以頂層獨立 `---` 分頁，前後保留空行。一般閱讀仍然顯示連續 Markdown。單卡視窗提供分頁閱讀及記憶練習：第一頁是題目，其餘頁是答案；沒有分頁時使用標題與內文。

閱讀可設定明天、三天後、自訂日期或下一個固定間隔。記憶練習先回想、再揭示，選擇忘記、吃力想起、記得或輕鬆想起。揭示後手機左滑代表忘記，右滑代表記得；閱讀模式左右滑動換頁。完整按鈕操作也可使用。

目標保留率影響未來 FSRS 評分的排程；固定間隔只影響閱讀。筆記 status 與兩種排程分開管理。河道提供到期、未來、暫停與 status 篩選，也能按最早到期排序；篩選或排序中的自選河道保留原本的手動項目順序。

每個明確操作寫入 `.github-notes-study.yaml`，保留事件與最近操作撤銷。local 來源先存入檔案，再透過既有 Git 介面提交與同步；GitHub 來源直接以版本檢查提交至 main。其他裝置已修改時，畫面要求重新載入再操作。

修改正文後，相同且唯一的頁面可重新定位。內容有改變時，可以重新配對並選擇保留排程或重設記憶；固定卡片 ID 與事件歷史會保留。檔名變動的自動對應使用筆記原有的 metadata.id。

本版提供整份筆記的正反面卡。資料結構支援多張卡片、反向對應及文字遮罩；多題／填空編輯器、簡報模式與參數最佳化待後續開發。側錄檔上限為 4 MiB，達到上限會回報保存失敗，保留既有資料。
