# 分頁閱讀與學習泳道

新增泳道預設採用一般卡片版型。從泳道版型選單切換成「閱讀」或「學習」，便會一次顯示一張筆記卡片。學習泳道先顯示題目；按「揭示答案」後可使用前後頁按鈕往返題目與所有答案頁。泳道工具列的左右箭頭切換卡片，沿用篩選與排序，切卡不寫入評分。

正文以頂層獨立 `---` 分頁，前後保留空行。第一頁為題目，其餘頁為答案；沒有分頁時以標題為題目、內文為答案。Live Preview 編輯器顯示分頁邊界與頁面間距，Source 保留原始 Markdown。程式碼與巢狀內容中的分隔線保留原意。

在「編輯泳道」選擇閱讀或學習版型，設定各階段的 note status 與間隔天數。熟悉程度決定目的階段：

- 忘記：第一階段。
- 吃力：目前階段。
- 記得：下一階段。
- 輕鬆：向前兩階，超過上限停在最後階段；也可設定直接到最後階段。

到期時間使用目的階段的間隔。保存成功後更新筆記 status 並換下一張；依 status 篩選的其他泳道會自動呈現該卡。閱讀泳道也可隨選筆記、略過或自訂延後時間。閱讀事件與回想事件分開記錄。

學習泳道的工具列提供全部、到期、未來、暫停篩選；筆記狀態與排序共用同一列。最早到期和標題等排序是同一選單中的互斥選項。手機由「篩選與排序」展開控制；各頁側欄開關與筆記本選單同列。答案揭示後左滑代表忘記、右滑代表記得；閱讀泳道左右滑動換頁。

按泳道標題旁的「泳道全螢幕」進入 `/screen/lanes/<id>` 專屬頁，可加入書籤或直接重新載入。專屬頁保留該泳道版型、選卡、翻頁、評分、撤銷與編輯設定；返回屏幕會定位原泳道。開啟筆記編輯器後，關閉也回到原泳道專屬頁。

每次評分一起保存筆記 status 與 `.github-notes-study.yaml` 的階段、到期時間及事件。local 來源先存入檔案，再透過既有 Git 介面提交與同步；GitHub 來源以同一個版本檢查 commit 保存兩份檔案。最近操作可撤銷，保存失敗會停留原卡並提供重試。全螢幕時返回屏幕即可使用 Git 提交介面。

內容修改後，相同且唯一的頁面可重新定位；有歧義時需明確重新配對。固定卡片 ID、既有 FSRS 排程與歷史保留，新泳道流轉以階段間隔為準。示範原稿及泳道配置位於 [examples/study](../../examples/study/)。

本版提供整份筆記的正反面卡。多題／填空編輯器與完整簡報模式屬後續功能。學習側錄檔上限為 4 MiB，達到上限會回報保存失敗並保留資料。
