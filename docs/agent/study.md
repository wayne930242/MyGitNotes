# 分頁閱讀與學習頁

河道版型維持縮圖、小、中。按河道工具列的「開始學習」，直接進入該河道的全螢幕學習頁，河道原本的 view 與排序保持原值。學習頁固定按最早到期排序，navbar 將返回、學習／閱讀切換、篩選及設定排成一列。

學習頁一次顯示一張筆記卡片，先顯示題目；按「揭示答案」後可往返題目與所有答案頁。前後卡片箭頭沿用目前學習篩選及到期順序，切卡不寫入評分。切換「閱讀」可自由翻頁、選卡或延後。

正文以頂層獨立 `---` 分頁，前後保留空行。第一頁為題目，其餘頁為答案；沒有分頁時以標題為題目、內文為答案。Live Preview 編輯器顯示分頁邊界與頁面間距，Source 保留原始 Markdown。程式碼與巢狀內容中的分隔線保留原意。

從學習頁的編輯按鈕開啟河道設定，調整各階段的 note status 與間隔天數，套用與取消共同處理整份配置。熟悉程度決定目的階段：

- 忘記：第一階段。
- 吃力：目前階段。
- 記得：下一階段。
- 輕鬆：向前兩階，超過上限停在最後階段；也可設定直接到最後階段。

到期時間使用目的階段的間隔。保存成功後更新筆記 status 並換下一張；依 status 篩選的其他河道會自動呈現該卡。閱讀河道也可隨選筆記、略過或自訂延後時間。閱讀事件與回想事件分開記錄。

學習頁 navbar 提供全部、到期、未來、暫停篩選，篩選保存在網址，重新載入會保留。河道原本的筆記狀態篩選決定候選卡片；學習頁的篩選不改變一般河道的呈現。手機答案揭示後左滑代表忘記、右滑代表記得；閱讀時左右滑動換頁。

`/screen/lanes/<id>` 是河道的專屬學習網址，可加入書籤或直接載入。返回屏幕會定位原河道；開啟筆記編輯器後，關閉也回到原學習頁。進入學習頁不產生筆記或配置寫入，沒有個別配置時使用預設階段。

每次評分一起保存筆記 status 與 `.github-notes-study.yaml` 的階段、到期時間及事件。local 來源先存入檔案，再透過既有 Git 介面提交與同步；GitHub 來源以同一個版本檢查 commit 保存兩份檔案。最近操作可撤銷，保存失敗會停留原卡並提供重試。全螢幕時返回屏幕即可使用 Git 提交介面。

內容修改後，相同且唯一的頁面可重新定位；有歧義時需明確重新配對。固定卡片 ID、既有 FSRS 排程與歷史保留，新河道流轉以階段間隔為準。示範原稿及河道配置位於 [examples/study](../../examples/study/)。

本版提供整份筆記的正反面卡。多題／填空編輯器與完整簡報模式屬後續功能。學習側錄檔上限為 4 MiB，達到上限會回報保存失敗並保留資料。
