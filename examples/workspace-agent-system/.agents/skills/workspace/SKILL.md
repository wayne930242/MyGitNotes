# 工作區筆記

1. 閱讀根目錄與目標筆記本的 `AGENTS.md`。
2. 確認目標筆記與相關內容，再依使用者指示修改；保留未知 frontmatter 欄位。
3. 檢查差異與相關連結，提交時僅包含本次工作範圍。

建立或整理 `index.md` 時，先閱讀 `docs/agent/product/skills/github-notes-workspace/SKILL.md` 的「資料夾索引」規則，確認根目錄、卡片行為及相對連結。

本技能由工作區擁有者自行維護，Core 更新不會覆蓋它。
