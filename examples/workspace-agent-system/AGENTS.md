# 工作區 Agent 指引

本檔案與 `.agents/`、`.codex/` 由本工作區自行管理，請在 `main` 分支追蹤與提交修改。Core 更新會保留這些設定。

- 修改筆記前先閱讀相關筆記與筆記本指引，保留使用者內容及 frontmatter。
- 介面與產品原始碼的修改先在 `github-notes` 的 `core` 分支完成，通過測試、建置並推送 Core 後，再於本工作區執行 `pnpm update-core`。
- 工作區更新前確認位於 `main` 且工作目錄乾淨；更新後完成測試、建置與資料完整性檢查，再推送工作區。
- 不將憑證、API 金鑰或 Agent 執行紀錄提交至 Git。

可在此補充本工作區的語言、角色、寫作及協作慣例。
