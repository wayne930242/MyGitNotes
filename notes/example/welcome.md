# 歡迎使用 GitHub Notes

這套範例同時是日常筆記模板與操作教學。內容維護在產品 `core` 分支的 `examples/demo-workspace`，正式範例工作區 `main` 使用同一份內容。

## 從這裡開始

1. 閱讀 [編輯與提交](getting-started/edit-and-commit.md)，試試本機保存與 Commit。
2. 用 [每週回顧](projects/weekly-review.md) 記錄正在處理的事。
3. 把尚未整理的想法放進 [閱讀清單](projects/ideas/reading-list.md)。
4. 閱讀 [狀態與封存](getting-started/status-and-visibility.md)，了解預設狀態。

List 適合快速開啟筆記；Card 適合瀏覽內容摘要；Kanban 依狀態分欄。筆記中的狀態選單可以直接操作，修改後由底部 Commit 列統一提交。

公開網站可直接閱讀；登入 GitHub 並具有儲存庫寫入權限後，就能編輯。
