# Graph Playground

Start here, select nearby nodes, and expand them into editable note cards.

- [Riverside Reading](river-reading.md): a note with an image.
- [Evening Ideas](evening-ideas.md): another image and links back to related notes.
- [Music and Resources](music-resources.md): YouTube and image previews.
- [Dated Tasks](todo-demo.md): tasks you can check off in the to-do tool.

Try moving two cards side by side, resizing them, and dragging a connection handle to another note. Select a few notes and save them as your own swimlane.
